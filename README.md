# ClassNote · 课堂知识库

课堂录音与学习知识库。课程目录、连续文档、正文图片和录音放在同一个学习空间里，不内置 AI。

支持本机版和私人线上版。线上版使用登录账号、Supabase 私有数据库和附件存储，部署在 EdgeOne；配置和容量说明见 [线上版说明](docs/ONLINE.md)。本机版的数据保存在电脑，线上版的数据保存在云端，两套资料独立，不会自动迁移。

## 本机版使用

当前电脑已安装依赖并完成构建。双击 **打开课堂知识库.cmd**，浏览器会打开 [本机知识库](http://127.0.0.1:3210)。关闭网页后服务继续运行；双击 **停止课堂知识库.cmd** 可以停止。停止前请确认笔记显示“已保存到本机”。重启电脑后需再次打开，没有设置开机自启动。

其他电脑首次运行，需要 Node.js 24 或更新版本。在项目目录执行：

```powershell
npm ci
npm run build
npm start
```

开发运行使用 `npm run dev`。只能启动一个占用 3210 端口的实例。修改代码后重新构建并重启生产服务才能看到更新。没有 Node.js 的电脑不能直接双击运行。

## 日常流程

1. 创建课程，再添加课堂记录；课堂标题、日期可以直接编辑。
2. 上传或拖入 MP3、M4A、WAV 等录音。录音进入常驻上传列表，上传时可在同一网页内切换课堂、继续编辑，文件仍保存到开始上传的课堂；失败可重试。请保持标签页打开，刷新、关闭网页或关闭浏览器会中断尚未完成的上传。支持多段录音、快退/快进 15 秒、拖动、倍速、音量、原文件下载、重命名、替换和删除。浏览器不支持解码的文件会显示提示。
3. 直接粘贴 Markdown，或拖入 Markdown/TXT 文件、点击“导入笔记”，预览后追加。文件导入同时保留原文，方便检查复杂格式。独立 `$$...$$` 公式支持 KaTeX；行内公式保持原文，本版未实现行内公式编辑。
4. 在正文定位光标，点击“插入图片”；也可以把多张图片拖到笔记对应段落，或粘贴图片。录音和图片一起拖入时会分别导入。图片作为块出现在段落之间，左侧手柄可拖动，左右边缘可调整显示宽度。图片菜单支持说明、替换、删除等操作。编辑模式双击图片放大，阅读模式单击放大。
5. 自动保存约延迟 750ms；本机版显示“已保存到本机”，线上版显示“已保存到私人云端”，均在数据库写入成功后才显示。如果失败，请保持页面打开并重试，或导出草稿。未保存时切换课堂会被阻止，关闭页面会提示。

搜索支持课程、标题和正文；右侧大纲根据标题生成。默认使用柔和炭黑主题，右上角“深色／浅色”按钮可随时切换，并记住选择。知识库设置中也可以切换主题、显示归档课程、导出完整备份和恢复备份。Ctrl + K 可定位搜索栏。

## 本机版的数据与备份

默认存储位置是项目内的 `.classnote`：

| 路径 | 内容 |
| --- | --- |
| `.classnote/library.sqlite` | 课程、课堂、BlockNote JSON、附件信息与设置 |
| `.classnote/files/` | 原始录音和图片 |
| `.classnote/tmp/` | 上传/恢复期间的临时文件 |

这些内容均被 `.gitignore` 排除，**GitHub 源代码仓库不等于知识库备份**。不要删除 `.classnote`，也不要只复制 SQLite 主文件而遗漏 WAL 和附件。通过界面的“导出完整备份”下载 ZIP，再复制到其他磁盘。浏览器下载开始不代表文件已下载完成，请检查下载列表。

恢复会校验清单、关联、文件大小与 SHA-256，然后分配新 ID 追加导入，**不覆盖现有资料**。重复恢复会产生重复课程。当前主题与最近打开记录不被覆盖；备份清单包含原设置供查阅。恢复时请保持页面打开。完整备份以流处理，最大 64 GB；单个音频最多 8 GB，单张图片最多 50 MB，Markdown 文件最多 4 MB，笔记 JSON 最多 8 MB。

删除课程或课堂需要确认。被移除的文件暂时保留在磁盘，避免中断进行中的备份；本版没有自动清理或回收站恢复界面，删除不会立即释放附件占用的空间。完整备份只包含现有记录的附件。

高级用法：可用环境变量 `CLASSNOTE_DATA_DIR` 指定独立的绝对数据目录。先停止服务，再完整搬迁数据并设置环境变量；不要在运行期间更换目录。自定义目录由你负责备份和 Git 排除。

## 访问方式

本机版只监听 `127.0.0.1`，拒绝跨站 API 请求。线上版必须显式配置云端模式、网站地址和指定账号，使用私有数据库与附件桶；未配置时拒绝公网读取，避免误用电脑上的临时存储。详见 [线上版说明](docs/ONLINE.md)。

## 验证与开发

```powershell
npm run typecheck
npm test
npm run build
```

架构与实施方案见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)，线上配置见 [docs/ONLINE.md](docs/ONLINE.md)，测试记录见 [docs/VERIFICATION.md](docs/VERIFICATION.md)。本机浏览器验收使用独立测试目录；线上验收仅创建临时课程并在完成后清理。

编辑器使用 [BlockNote 开源核心](https://www.blocknotejs.org/docs/getting-started)；笔记 JSON 为原始保存格式，Markdown 为辅助交换格式。Markdown 导出的图片仍指向知识库附件 API，独立迁移请使用完整 ZIP 备份。
