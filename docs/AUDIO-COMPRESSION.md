# 课堂录音批量压缩

双击项目根目录的 **课堂录音批量压缩.cmd**，打开本机压缩窗口。当前电脑已准备好组件；其他电脑首次使用先运行 **安装录音压缩组件.cmd**，需要 Node.js 和 Windows。

## 使用流程

1. 先使用原录音完成转写、内容整理和重点提取，保留原文件。本工具负责压缩，不负责自动转写或总结。
2. 在压缩窗口中添加多份录音或整个文件夹，也可以把文件或文件夹从资源管理器拖到列表中。
3. 选择档位并开始压缩。默认保存到项目根目录下的 **压缩录音** 文件夹，也可以更换目录。
4. 压缩完成后双击列表中的结果，使用电脑默认播放器试听。确认远处人声、专业术语和英语等内容仍可辨认，再上传压缩版。

| 档位 | 输出 | 90 分钟粗略大小 |
| --- | --- | --- |
| 较清晰 | AAC / M4A，64 kbps，单声道，32 kHz | 约 43 MB |
| 更省空间 | AAC / M4A，32 kbps，单声道，32 kHz | 约 22 MB |

实际大小受编码器、内容和封装开销影响。以上是有损压缩，课堂人声质量应通过试听决定。原录音已经是低码率时会跳过，避免反复转码造成损失。这里没有自动降噪、裁剪静音、改变速度或时长的处理。

## 文件保护和结果

- 原文件仅用于读取，结果另存；同名结果会加序号，不覆盖现有文件。
- 每份录音先写临时文件，压缩后检查时长并完整解码，确认有效后生成正式结果。停止任务会清理本工具的未完成临时文件，已完成结果保留。
- 单份失败后继续处理后续录音。压缩记录保存在结果目录，包含原路径、结果路径、大小、时长、结果 SHA-256 和失败信息。
- 不上传音频，不自动替换或删除 ClassNote 云端录音。压缩本机文件不会直接释放云端空间。
- 批量任务按顺序执行。输出目录、压缩组件和本机任务记录已在 Git 中忽略，录音不会随代码提交。

## 组件来源

使用 [FFmpeg 官方下载页](https://ffmpeg.org/download.html) 推荐的 [gyan.dev Windows 构建](https://www.gyan.dev/ffmpeg/builds/)，版本 9.0.2 essentials。优先使用该构建者的 GitHub 镜像，备用下载地址为 gyan.dev。下载到本项目 `.tools/audio`，不修改系统环境变量；下载后校验 SHA-256：

`60f467265b1e312373dbcd92200c2618a74850f98d3d078e94296bb3fa2047ba`

安装包不是 FFmpeg 官方直接发行的 Windows 二进制；它由官网推荐的构建者提供。组件无需上传到 GitHub。也支持电脑已有的 FFmpeg / ffprobe。

## 验证记录（2026-10-17）

一份真实课堂录音：128 kbps 双声道 AAC，时长 5863.352 秒，原大小 95,503,385 字节。

- 64 kbps：49,414,042 字节，减少约 48%，本机压缩及校验约 28 秒。
- 32 kbps：26,162,174 字节，减少约 73%，本机压缩及校验约 38 秒。
- 两份结果均完整解码通过，时长均为 5863.352 秒。实际试听和其他录音的听感需要使用者确认，以上不代表所有录音都能达到相同压缩率或速度。
- 4 项自动测试覆盖：原文件和同名文件保护、重复和输出目录排除、低码率跳过及坏文件后继续、停止后临时文件清理。
- Windows 窗口实际启动、文件选择对话框添加真实录音、点击开始、进度更新和完成状态已验证。资源管理器的物理拖放、默认播放器听感留待实际使用确认。

压缩只能减缓空间增长；长期课堂录音仍需要足够的云端容量，或经过验证的归档和清理流程。
