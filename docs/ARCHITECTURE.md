# ClassNote V1 架构与实施方案

## 已确认的环境

Windows 本机；Node.js 24；已有 Git 仓库，原始项目没有框架。用户已明确选择本机运行、数据保存在电脑。因此本版不注册或发布云端站点，不开放局域网或公网访问。

## 架构

Next.js App Router + React + TypeScript + Tailwind；BlockNote 开源编辑核心与 Mantine 编辑控件；Lucide 图标。服务绑定 127.0.0.1:3210。使用 Node 内置 SQLite（WAL、外键、事务），附件独立存放于 `.classnote/files`，数据库为 `.classnote/library.sqlite`。可通过 CLASSNOTE_DATA_DIR 指定绝对路径；启动后不要随意切换数据目录。

## 数据模型

- courses：UUID、名称、颜色、简介、归档标记、创建时间。
- lessons：UUID、courseId 外键、标题、日期、BlockNote 原生 JSON、版本号、创建/修改/访问时间。
- attachments：UUID、lessonId 外键、类型、显示名、受控随机文件名、MIME、字节数、SHA-256、播放位置、创建时间。
- settings：键与 JSON 值，用于主题、折叠状态等。

关联通过 UUID 而非显示名。附件路径由服务生成，不能由客户端指定。删除记录需要确认，实体文件保留待清理以避免破坏已引用内容；完整备份仅包含活跃记录和对应附件。图片 URL 为本机 API 的稳定 ID 引用，不写 Base64。

## V1 实施顺序

1. SQLite 结构、受控附件目录、输入校验、本机同源访问保护。
2. 三栏布局、课程与课堂 CRUD、日期排序、移动、归档。
3. BlockNote、原生 JSON 保存、串行防抖保存、版本冲突检测；失败时保留本地编辑并阻止切换。
4. 图片上传回调、正文插入、块移动、缩放、粘贴、拖放和放大。
5. 大文件流式上传与真实进度、多音频播放、Range 分段读取、倍速及位置记忆。
6. Markdown 预览、追加导入、原文保留；搜索、动态大纲、阅读与深色模式。
7. 完整 ZIP 备份与校验后追加恢复，避免覆盖现有资料。
8. 类型检查、生产构建、存储/API 回归和真实浏览器验收。

## 可靠性边界

大型音频直接从请求流写入文件，不通过 JSON、Base64 或整体 formData 内存解析。上传成功需要文件落盘、哈希完成和数据库登记。笔记保存采用 revision 乐观锁，防止多标签页覆盖。窗口关闭前提示未保存内容，并将小型笔记草稿暂存为恢复副本；草稿不是保存成功的证据。文件和数据库被 Git 忽略。

备份导入先验证版本、关联、路径、长度及哈希，再用新 ID 追加；不覆盖现有课程。公网部署须另行设计身份认证、私有附件访问和持久化存储，本版不可直接把监听地址改为公网地址。

## 视觉方案

色彩：纸白 #FAFAF9、侧栏 #F3F3F1、文字 #303235、次级文字 #85868D、紫色 #7460AA、线条 #E7E7E4。使用系统中文无衬线字体，正文 16px/1.75，正文最大宽度 800px，标题 32px。桌面侧栏 250px、大纲 220px；窄屏自动收起大纲。用一份连续文档承载课堂内容，以紫色活动轨迹标记选中课堂，避免统计卡片和装饰动画。

## 验收边界

自动化测试和浏览器实测分别记录。不把合成音频的播放验证当成用户真实 90 分钟录音验收；没有用户提供的真实录音时明确保留这一项。图片插入、移动和刷新持久化须使用真实浏览器和真实文件验证。
