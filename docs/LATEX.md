# 正文中的 LaTeX 公式

刷新网站后，可以直接输入或粘贴包含公式的笔记。公式和普通文字可以放在同一个段落、列表或表格里。

| 用法 | 示例 |
| --- | --- |
| 行内公式 | `$E=mc^2$`、`\(\frac{a}{b}\)` |
| 独立公式 | `$$\int_0^1 x\,dx=\frac12$$`、`\[a^2+b^2=c^2\]` |
| 插入公式 | 点击正文上方“公式”，或输入 `/` 后选择“块级公式”“行内公式” |
| 修改公式 | 编辑模式下点击公式，修改 LaTeX 源码，点击“确定” |

独立公式支持多行 `aligned`、`cases`、矩阵等常见数学环境。输入 `$$` 后按空格，也可以先创建空公式，再输入源码。错误公式会提示修改并保留源码，不会清空笔记。

“导入笔记”的预览和正文粘贴使用相同的转换逻辑；导出 Markdown 时保留公式源码。代码块和行内代码中的 LaTeX 示例保持原文。原有公式块会在编辑器中兼容显示，打开笔记不会执行数据库迁移或改动附件。

数学语法由 KaTeX 渲染。已有普通正文中的完整公式分隔符也会在打开时识别；复杂导入内容仍可先检查预览。
